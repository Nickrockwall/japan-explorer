# 朝鲜半岛模式 · 设计

日期：2026-11-01　状态：已确认（2026-11-01）

## 1. 意图

在 Japan Explorer 里加一个「朝鲜半岛」模式，用同一套外壳（地图、详卡、时代滑块、我在哪、古今户籍、AI 向导）讲半岛的古今政区。用户主要面向中文、英文、日文读者，这是个人兴趣项目，不追求流量。

为什么是半岛：制度结构与日本最像（三国 → 新罗九州 → 高丽五道两界 → 朝鲜八道 → 十三道 → 今天），道名今天还在用，地名有汉字，边界数据授权宽松（见 §5）。

## 2. 用户已经决定的

| 事项 | 决定 |
|---|---|
| 形式 | 同一网站里「日本 / 朝鲜半岛」切换，不另开站点，不把两国画在同一张图上 |
| 名称 | 不能只叫「韩国」。模式名用地理名：朝鲜半岛 / Korean Peninsula / 朝鮮半島。1945 年前的各时代覆盖整个半岛，现代层南北都画 |
| 界面语言 | 只做中、英、日，不加韩文界面 |
| 地名读音 | 像日本版的「漢字 / かな / Romaji」那样写「汉字 / 한글 / 罗马字」，如 庆尚北道 / 경상북도 / Gyeongsangbuk-do |
| 争议地区 | 标注「双方有争议」，两个名字并列 |
| 共同历史 | 分开讲日本方面与韩国方面的看法 |
| 视觉 | 只换皮（配色、纸张质感、纹样、印章样式、音效与音乐），布局与操作不变 |

## 3. 我（Claude）的做法与取舍（用户可推翻）

- **争议标注细节**：两个名字并列，两种模式里都用同一个固定顺序，不随模式变化：岛写「独岛 / 竹岛（有争议）」（先写实际管辖方的叫法）；海写「日本海 / 东海」（先写国际水道组织 IHO 现行图集的叫法）；岛屿不涂任一方颜色，点开后列双方主张与实际管辖现状，不下结论。南北之间画「军事分界线」（1953 年停战线），不叫国界。
- **共同历史的写法**：措辞用「日本方面的主流叙述 / 韩国方面的主流叙述」而不是「日本人认为」；每个事件分三层：双方都承认的事实 → 叙述的分歧（评价、称呼、责任） → 来源。有充分史料的事实不做假平衡。必要时加朝鲜方面的叙述。两种模式看到的是同一份内容。
- **视觉**：丹青五方色（青赤黄白黑）、韩纸质感、传统纹样；**不用**太极旗、朝鲜国旗、任何一方国徽的元素。音乐用合成的五声音阶（伽倻琴风格）。
- **模式切换**：深链接 `#map=korea`（不用 `kp` / `kr`，它们是朝鲜、韩国各自的国家代码）；不带时为日本，现有链接全部照旧可用。

## 4. 目标 / 非目标 / 反目标

**目标**
- 日本模式行为与现在完全一致（smoke 全过，截图无变化）。
- 半岛模式第一版：南北现代一级行政区地图 + 详卡 + 历代政区时间轴 + 「道名今犹在」+「我在哪」+ 市郡级「古今户籍」。
- 每条数据有可核验的出处（沿用日本版「对照维基核实，核不了就不收」）。

**非目标**
- 韩文界面；把日本与半岛画在同一张图上；邑面洞一级的历史沿革。
- 日本独有功能的半岛版本（御朱印、拉面、地酒、广重、石高、合战沙盘）第一版不做，半岛模式下隐藏。以后可以有半岛自己的对应物，届时另议。

**反目标（做出来也算失败）**
- 任何一方读起来觉得网站在替另一方表态（争议地区上色、单方面的历史叙述、国旗国徽元素）。
- 把半岛叫成「韩国」或只画南边。
- 改造过程中把线上日本版弄坏。
- 为了填满而编造数据（没有出处的沿革、人口、地点）。

## 5. 数据来源与授权（已核实）

| 数据 | 来源 | 授权 |
|---|---|---|
| 韩国一级区（17） | geoBoundaries KOR ADM1（取自 Natural Earth） | 公有领域 |
| 韩国市郡区（228，2020） | geoBoundaries KOR ADM2（citypopulation.de） | CC BY 3.0 |
| 韩国邑面洞（3504，2018） | geoBoundaries KOR ADM3（KoStat） | 韩国公共 누리 第 1 类（注明出处） |
| 朝鲜一级区（11，2018）与市郡（179，2019） | geoBoundaries PRK ADM1/ADM2（WFP、OCHA ROAP） | CC BY 3.0 IGO |
| 沿革、读音等文字 | 维基百科（中 / 日 / 韩）、Wikidata | CC BY-SA 4.0 / CC0（按现有规矩登记，不并入 NC 内容） |

以上都只要求署名，可以随站点发布（对比 CHGIS：禁止再分发，不能用）。

**已发现的数据问题**（构建脚本里处理）：
- 韩国 ADM1 与 ADM2 来源不同、海岸线不一致 → 一级区由 ADM2 按空间归属合并得到，不直接用 ADM1。
- 南北两份数据在分界线附近重叠约 245 km²、另有几块 6–67 km² 的缝隙（都在 4 公里宽的非军事区内）→ 重叠部分按南侧裁掉北侧，缝隙并给相邻单元，再像 `build_provinces.py` 那样整体 `coverage_simplify`，保证南北共用同一条边。
- 朝鲜数据只有 11 个一级区（无罗先单列，开城并入黄海北道），韩国数据是 2020 年前后的名称（江原、全北此后改为特别自治道）→ 名称以维基核实为准，界面注明数据年份。
- 独岛 / 竹岛不在任何一份数据里 → 单独画点或小面，按 §3 处理。

## 6. 第一版的内容

1. **切换与外壳**：顶栏国家开关；数据路径按国家分开（`src/data/jp/…`、`src/data/korea/…`，日本数据先原地不动，见 §7 第 1 步）。日本独有功能在半岛模式下隐藏。
2. **地图**：南北现代一级区，点进去是市郡区下钻；军事分界线；独岛 / 竹岛与海名标注；图例注明来源。
3. **详卡**（每个一级区约 28 个）：汉字 / 한글 / 罗马字名、人口面积、历史时间轴（固定段：三国 / 新罗 / 高丽 / 朝鲜王朝 / 近代（1897–1945）/ 现代）、名胜、物产、方言、地缘梗（轻松向，不碰南北政治）。先写中文底本，英日为覆盖层，沿用现有 i18n 结构。
4. **历代政区时间轴**：685 新罗九州、1018 高丽五道两界、1413 朝鲜八道、1896 十三道、今天。做法与日本 68 国一样：每个市郡标出各时代归属，再合并成各时代的面，同一批边一起简化。三国时期边界变动太大，第一版只在时间轴上显示说明，不画面（见 §8）。
5. **道名今犹在**：庆尚、全罗、忠清等由两州首字合成的道名来历，以及南北各有一个的江原道。
6. **我在哪 / 古今户籍**：定位或选一个市郡 → 列出它在新罗、高丽、朝鲜王朝各属哪个州 / 道 / 府郡县。南边按韩文维基各市郡条目的「연혁」核实；北边精度较粗，界面写明。
7. **AI 向导**：半岛版史官人设与快捷提问；System Prompt 加入争议与共同历史的写作规则（§3）。
8. **共同历史**：第一版先做 2–3 个事件（如壬辰战争、1910–1945 年日本统治），按三层结构，在两种模式里都能打开。

## 7. 实施顺序（每一步单独可上线）

1. **国家抽象（无可见变化）**：store / map / app / detail / guide 等模块里写死的「47 县、68 国、japan.json」改为从当前国家的配置读取；日本配置就是现在的数据。smoke 全过、截图无变化才算完成。
2. **半岛底图 + 皮肤**：构建脚本 `tools/build_korea_geo.py`（geoBoundaries → 一级区 / 市郡 GeoJSON）、国家开关、争议与分界线标注、丹青皮肤、地名三读法。详卡先只有名称、读音、人口面积。
3. **详卡内容**：约 28 个一级区的中文底本，再英日覆盖层。
4. **历代政区时间轴**：市郡 → 各时代归属对照表（维基核实工具）+ 底图合并。
5. **道名今犹在、我在哪、古今户籍**。
6. **共同历史、AI 向导人设、音乐、新手教程的半岛版**。

每一步都补 smoke 场景、更新 CLAUDE.md 与三语 CHANGELOG，推送前问用户。

## 8. 日本模式的争议地区（用户 2026-11-01 选定）

`japan.json` 现在把竹岛画成岛根县的一部分，把北方四岛画成北海道的一部分（地球地図日本即日方立场）。为与 §3 一致，**日本模式里这两处也改成「有争议」的标法**：岛不涂县色，点开说明各方主张与实际管辖现状。北方四岛市町村下钻里的 `remote` 岛同样处理。放在第 2 步与半岛标注一起做（同一套组件）。
