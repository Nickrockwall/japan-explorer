# 视觉改版：国絵図（2026-11-08）

## 依据

江户幕府命各藩按令制国绘制的「国絵図」：楮纸上刷胡粉，海用群青淡刷，山用绿青，郡界朱线，村落画成按郡分色的小判形椭圆，地名写在纵长的短册（白签）里，角上有凡例与题签。本站本来就以 68 国为骨架，所以画法照搬它的规矩，而不是泛泛的「和风」。

## 颜色（单一浅色主题）

| 名 | 值 | 用途 |
|---|---|---|
| 楮紙 | `#E7DEC6` | 页面底色、顶栏 |
| 胡粉 | `#F4EFE2` | 卡片、陆地底色 |
| 群青（淡） | `#93AEB9` | 地图海面 |
| 墨 | `#2A2520` | 正文、边线、选中的筛选按钮 |
| 朱 | `#B3302A` | 只用于「印」：品牌印章、当前选中、主按钮、盖印 |
| 黄土 | `#7A5719`（字）/ `#D9B96E`（填色） | 已探索、次要强调（原 `--kin`） |

次要文字 `#4F473D`，弱化文字 `#6B6155`（在三种纸色上对比度都 ≥4.5）。数据配色（八地方、五畿七道、战国各家、幕末、拉面、地酒、国力色阶）改用岩绘具色系的中明度色，标签一律墨字 + 纸色描边，每组都检查与胡粉陆地、相邻色、墨字的对比。

## 字体

不加网络字体（保持 3.19 的首屏预算）：标题与地图标签用当前语言的一种 Noto Serif，正文用系统无衬线。字号阶 12 / 13.5 / 15 / 18 / 22 / 28，标题字距 .04em，不用全大写。

## 版式

结构不变（左地图 58%，右详卡 + 向导；手机三标签页）。

左对齐；卡片圆角 3px，层级靠纸色深浅（楮紙 → 胡粉）与一条墨线区分，不用阴影；浮在地图上的卡片加一道 2px 的硬投影（墨 12%）与海面分开。

## 原则

1. 大胆只在地图：群青海、胡粉陆地、墨线、纵书短册标签、小判形凡例。界面其余部分安静。
2. 朱 = 印。只给盖印、当前选中、主按钮与品牌印章；其他强调用墨或黄土。
3. 去掉青海波底纹与各处发光阴影（深色主题时代的做法）。
4. 半岛模式只保证可读，不另行设计。

## 自查

最接近的套路是「奶油底 + 衬线标题 + 陶土色点缀」。区别：屏幕上面积最大的是群青海面而不是奶油底；底色取楮纸的黄土调（`#E7DEC6`），比 `#F4F1EA` 深、偏黄；强调色是偏冷的朱（`#B3302A`），而且只用于「印」；纵书短册与小判凡例直接来自国絵図的画法。
